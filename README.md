# Couple Chat Insights · 情侣聊天深度分析

> 用心理学框架分析你们的微信聊天记录，看清这段关系的真实状态。

---

## 这是什么？

一个纯本地运行的情侣聊天记录分析工具。

它不是简单的"数消息条数"，而是用**Gottman婚姻研究**、**依恋理论**、**Sternberg爱情三角**等经过40年验证的心理学框架，从你们的聊天记录里读出：
- 关系健康分（0-100）
- 四骑士信号（批评/蔑视/防御/筑墙）
- 依恋风格匹配度
- 爱情三角三维度
- 谁更投入、谁在逃避

---

## 为什么用这个？

| 其他工具 | 这个 |
|---|---|
| 只是数消息条数 | 用心理学框架解读 |
| 词云、点赞数 | 关系健康分、四骑士预警 |
| 需要上传数据到服务器 | 纯本地运行，隐私零泄露 |
| 需要装一堆依赖 | 纯Python标准库，开箱即用 |

## 快速开始

### 1. 准备聊天记录

先用提取工具把微信聊天记录导出成TXT格式：
- 推荐工具：[WeChatMsg](https://github.com/LC044/WeChatMsg) 或 [chatlog](https://github.com/sjzar/chatlog)

导出格式示例：
```
2024-01-15 22:30 | 我 | 宝贝在干嘛呢
2024-01-15 22:31 | TA | 刚洗完澡呀
2024-01-15 22:31 | 我 | 想你了
```

### 2. 运行分析

```bash
# 不需要装任何第三方库！
python analyze.py 你的聊天记录.txt

# 自动生成：你的聊天记录_分析报告.html
# 用浏览器打开就行
```

### 3. 看报告

浏览器打开生成的HTML文件，就能看到完整的深度分析报告。

## 报告包含什么？

### 🌟 综合健康分（0-100）
五个维度加权：Gottman比率、关心投入、冲突修复、断联频率、四骑士频率。

### 💑 爱情三角理论
亲密、激情、承诺三个维度分别打分，看看你们是完美之爱、浪漫之爱、还是伴侣之爱。

### ⚔️ Gottman 四骑士
批评、蔑视、防御、筑墙——这四个信号是关系破裂的最强预测指标。其中**蔑视**是头号杀手。

### 🔗 依恋风格
从语言行为反推你们是焦虑型还是回避型，看看是不是陷入了"追逃模式"。

### 📊 互动节奏
谁回得快、谁更主动、最长断联多久、吵了几次架。

## 隐私说明

✅ **纯本地运行**：所有分析都在你的电脑上完成
✅ **零网络请求**：不会上传任何聊天记录
✅ **开源可审计**：代码全部公开，你可以一行一行看
✅ **看完就删**：报告生成后，你想删就删

## 技术说明

- **纯Python标准库**：不需要pip install任何东西
- **支持编码**：UTF-8 / GBK / GB18030 / Big5
- **自动识别发送者**：不用手动指定谁是谁
- **支持数据量**：1000条 ~ 10万条
